# 入力モードの一時表示

## 背景と目的

IME がオンかオフかは、タスクバーの入力モードのアイコン ([mode-icon.md](mode-icon.md)) でしか分からない。
入力を始める前、視線のあるキャレットの近くでは状態が分からず、打ってから日本語/英字の違いに気づく。

オン/オフの切替時と入力欄へのフォーカス移動時に、キャレットの近くに「あ」/「A」を短い時間だけ出す。

## 決定事項

### 出すとき

- IME のオン/オフが切り替わったとき (`GUID_COMPARTMENT_KEYBOARD_OPENCLOSE` の変化)。キー
  (半角/全角など) による切替もタスクバーのアイコンのクリックによる切替も含む
- 別の入力欄 (別の文書) にフォーカスが移ったとき。アプリの切替を含む
  - 同じ文書にフォーカスが戻っただけのときは出さない。ダイアログの開閉などで同じ入力欄に戻るたびに
    出ると目障りなため
  - 入力欄でないとき (モードのアイコンが × になる条件: フォーカスに context が無い、または
    `KEYBOARD_DISABLED`・`EMPTYCONTEXT` が立っている) は出さない
- アプリの起動時の IME の状態 ([ime-start-state.md](../archive/ime-start-state.md)) を適用したときは、適用後の状態を
  出す (適用前の状態を一瞬出してから切り替えない)
- QuicklIME の入力モードはオン (あ) とオフ (A) の 2 つだけなので、モードの変化はオン/オフの切替と同じ。
  モードを増やすときは同じ仕組みで出す
- 設定 `mode_popup` が 0 のときは出さない

### 中身と見た目

- オンなら「あ」、オフなら「A」の 1 字を、角丸の四角の中に出す
- 色は今の入力パネルのテーマ ([panel-theme.md](panel-theme.md)) の解決後の値を使う (ライト・ダークに追従)。
  背景は `background`、縁は `border` (テーマの `border on` のとき)、文字は `text`。角丸の半径は
  テーマの `panel_radius` を四角の大きさに収まる範囲で使う
- フォントは、モードのアイコン用に DLL のリソースに同梱した M PLUS Rounded 1c Regular のサブセット
  (「あ」「A」「×」) を使う。読めなければ Yu Gothic UI。リソースのフォントを読む DirectWrite の font loader は
  モードのアイコンと共通にする
- 大きさ: 四角の一辺は 96dpi で 28px (`MulDiv(28, dpi, 96)`。dpi はキャレットのあるモニタのもの)。
  文字サイズは「あ」の字形の外接矩形の長辺が一辺の 45% になる大きさとし、「A」も同じ文字サイズで描く。
  字ごとに外接矩形で上下左右の中央に置き、原点は整数 px に丸める (モードのアイコンと同じ置き方)
- アンチエイリアスはグレースケール
- ぼかし (テーマの `blur on`) と影は使わない
- 入力パネル・キャレットの印とは別の小さな layered window
  (`WS_EX_TOPMOST | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_LAYERED | WS_EX_TRANSPARENT`) で出す。
  フォーカスを奪わず、クリックは下のアプリへ通す

### 位置

- キャレットの矩形は `CaretRect` (選択範囲の矩形 → `GetGUIThreadInfo` のシステムキャレット) で取る
- 四角の左端をキャレットの矩形の左端に、上端をキャレットの矩形の下端に置く (キャレット行のすぐ下)
- キャレットのあるモニタの作業領域の下端からはみ出すときは、キャレット行の上 (四角の下端 = キャレットの
  矩形の上端) に出す。左右にはみ出すときは作業領域に収める
- 矩形が取れないとき、または入力位置がウィンドウの外を指して代わりの位置になったとき
  (`FallbackIfOutsideWindow`、[candidate-position-fallback.md](candidate-position-fallback.md)) は出さない。
  代わりの位置はキャレットの位置ではなく、状態と無関係な場所に出るため
- フォーカス移動の直後はアプリがまだキャレットを置いていないことがある。そのときに取れなければ出さない
  (取れるまで待ったり再試行したりはしない)

### 消すとき

- 出してから 1 秒で消す (タイマー)。フェードはしない
- 次のときは 1 秒を待たずにすぐ消す:
  - キー入力 (QuicklIME が処理するキーもアプリへ通すキーも)
  - フォーカスの移動 (移った先で出すなら出し直す)
  - 入力パネル・キャレットの印を出したとき (入力が始まったとき)
  - テキストサービスの終了 (`Deactivate`)
- 表示中に再び切り替えたときは、新しい状態の字で出し直し、1 秒を数え直す

### 設定

| キー | 値 | 既定 | 内容 |
|---|---|---|---|
| `mode_popup` | 0 / 1 | 1 | 切替時とフォーカス移動時に、キャレットの近くに入力モード (あ / A) を一時表示する |

- TSF 層が読む。エンジンは使わない
- 設定ツールの「表示」タブに、チェックボックス「オン/オフの切り替え時に「あ」「A」を表示する」を足す。
  フォーカス移動時にも出ることはラベルに入れず、利用者向けドキュメントで説明する
  ([config-input-display.md](config-input-display.md))

採らなかった案:

- IME オンの間、キャレットの近くに印を出し続ける案: 入力していない間はキャレットの移動 (クリック・
  スクロール) を知る手段が無く、印が違う場所に残る。常に出ていると目障りでもある
- 切替時の大きな表示と常時の小さな印の併用: 上と同じ理由で常時の印を採らない
- キャレットが取れないときにウィンドウ中央や画面中央に出す案: 視線から離れた場所に出ても気づきにくく、
  状態と無関係な場所に出す方が紛らわしい

## 実装手順

1. リソースのフォントの font loader と font face の読み込みを、モードのアイコンと一時表示で共通に使える形にする
   (モードのアイコンの見た目は変えない)
2. `ModePopup` (新規) を作る。キャレットの矩形・オン/オフ・テーマの色を受けて出し、1 秒で消す
3. 設定 `mode_popup` を TSF 層の設定に足す
4. TextService から呼ぶ: オン/オフの変化、別の文書へのフォーカス移動 (入力欄のときだけ)、起動時の状態の
   適用後に出す。キー入力・フォーカス移動・パネル/キャレットの印の表示・Deactivate で消す
5. 設定ツールに `mode_popup` を足す (読み書きとチェックボックス、既存の bool 設定と同じ形のテスト)
6. README.md と docs/design/README.md を更新する

## 検証方法

TSF 層の確認は CLAUDE.md の「安全なテスト環境」「エンジン検証の隔離」に従い、隔離した環境変数の PowerShell
からメモ帳で行う。

### テストケース

| # | 操作 | 期待 |
|---|---|---|
| 1 | メモ帳で IME オフ → 半角/全角でオン | キャレットの下に「あ」が出て、約 1 秒で消える |
| 2 | オン → 半角/全角でオフ | 「A」が出て約 1 秒で消える |
| 3 | タスクバーのアイコンをクリックして切替 | 切替後の状態の字が出る |
| 4 | 表示中にすぐ切り替える | 新しい字で出し直され、そこから約 1 秒で消える |
| 5 | 表示中に文字キーを打つ | すぐ消え、入力 (パネル・キャレットの印) が通常どおり出る |
| 6 | 表示中に矢印キーなどアプリへ通すキーを押す | すぐ消える |
| 7 | 別アプリからメモ帳へ Alt+Tab で戻る | 今の状態の字が出る |
| 8 | メモ帳で「名前を付けて保存」を開き、ファイル名の欄へ | その欄のキャレットの下に出る |
| 9 | 8 のダイアログを閉じてメモ帳の本文に戻る | 本文は別の文書なので出る |
| 10 | 同じ入力欄の中でフォーカスが外れずに再度 OnSetFocus が来る場合 (同じ文書) | 出ない |
| 11 | デスクトップをクリック (入力欄でない) | 出ない |
| 12 | 画面の下端近くにキャレットを置いて切替 | キャレット行の上に出て、作業領域からはみ出さない |
| 13 | 画面の右端近くで切替 | 作業領域に収まる |
| 14 | ime_start_apps でオフ指定したアプリを起動して入力欄にフォーカス | 「A」だけが出る (「あ」が一瞬出ない) |
| 15 | `mode_popup 0` にする | どの操作でも出ない |
| 16 | ライトテーマ・ダークテーマ・各組み込みテーマ | テーマの背景・縁・文字の色で出る |
| 17 | 150% / 200% の DPI のモニタ | DPI に合わせた大きさで、字がにじまず中央にある |
| 18 | 表示中に別の場所をクリック | クリックが下のアプリに届く。フォーカスが移れば消える |
| 19 | 設定ツールの「表示」タブ | チェックボックスがあり、保存で `mode_popup` が書き換わる |
| 20 | モードのアイコン (タスクバー) | 見た目・切替動作が変わっていない |
