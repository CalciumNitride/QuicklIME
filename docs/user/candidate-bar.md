# 候補バーと表示

## 候補バー

文字の入力中、キャレット行のすぐ下（画面下端に収まらない場合は上）に候補バーが横一列に表示されます。候補は確定や採用のキーを押したときだけ文書に入力され、候補を選択している間は文書内の入力テキストは変更されません。

### 候補の種類
候補バーには以下の種類の候補が表示され、各候補の先頭に番号（1〜9）が付きます（`Ctrl + 数字キー` でその番号の候補を採用できます）。表記が完全に一致する重複候補は自動的に 1 つにまとめられます。候補の最大表示件数は設定ツールの「候補バー」ページの「件数」(`max_predictions`: 9 / 18 / 27 / 36 件、既定値は 9 件) で変更できます。

- **英字候補**: [モードレス入力](modeless.md) により、現在の入力をそのまま英単語として確定できる候補です。入力文字数にかかわらず、常に候補バーの先頭に表示されます。英字モードの入力中は、大文字・小文字を自動補正した候補（例: `きょうはGitHub`）が表示されます。
- **全体変換**: 入力中のかな全体を変換した候補の上位（最大 3 件、かなと同じ表記を除く）です。キーの打ち間違いを自動で直した「補正候補」（[入力と変換](input.md) 参照）も含まれます。
- **予測候補**: 入力中のキーストロークから前方一致する単語の候補です（システム辞書、ユーザー辞書、確定履歴、直前の語に続けて確定したことのある単語など）。入力途中のローマ字（`arigat` で「ありがとう」）や、打ち間違いの補正（`arigtou` で「ありがとう」）も考慮して検索されます。

### 候補の並び順と見た目
- 英字候補の後に、全体変換候補と予測候補が尤度（確からしさ）の高い順に混ざって並びます。通常、入力を打ち終えた段階では全体変換の最良候補が先頭に来ます（全体変換の最良候補は必ず 1 ページ目に入ります）。学習やユーザー辞書に登録された候補が最良である場合、タイポ補正候補がそれより上位に表示されることはありません。
- 打ち間違いを補正した候補（全体変換の補正候補、および入力ミスを補正して検出した予測候補）には、横一列表示では `typo` カラーの枠線が付き、縦積み表示（`kind_tag on`）では「補正」タグが付きます。全体変換の補正候補は採用しても学習されませんが、予測候補は辞書にある正しい読みで学習されます。

### 表示条件とページ送り
- 確定済みのかなが `min_suggest_chars` 文字以上のときに表示されます。候補選択中は表示されません。モードレスの英字モード中は、入力全体が英字のときは大文字・小文字を補正した候補だけが表示され（補正する表記が無ければ候補バーは出ません）、前に日本語の部分があるときは日本語の部分の候補（[モードレス入力](modeless.md#日本語区間がある-run-の候補バー) 参照）と補正した候補が表示されます。変換エンジンとの通信が切断されているときは、英字の候補だけが表示されることがあります。
- 候補バーの水平方向の表示位置は、その入力セッションで最初に表示された位置に固定されます。
- 1 ページあたり最大 9 件表示されます。画面内に収まらない候補は次ページに送られます。複数ページある場合は現在のページ位置（例: `12/24`）が表示され、候補を選択していくと該当ページに自動で切り替わります。`Ctrl + 1`〜`Ctrl + 9` の番号は、現在表示されているページ内での番号に対応します。

### 候補の選択と採用範囲の調整
- **候補の選択**: `Tab` または `↓` で右へ進み、`Shift + Tab` または `↑` で左へ戻ります（未選択の状態から `Tab` を押すと先頭候補へ、先頭で `Shift + Tab` を押すと末尾候補へループします）。横一列テーマ (`layout row`) では、選択中は `→` / `←` でも移動できます（未選択時の `←` / `→` はアプリへ渡されます）。`Esc` を押すと候補の選択が解除されます。数字キー `1`〜`9` は候補の選択には使わず、ほかの文字キーと同じく入力されます。
- **採用範囲の伸縮**: 全体変換候補を選択しているときに `Shift + ←` を押すと、採用する範囲を末尾から 1 文節ずつ縮めることができます（`Shift + →` で 1 文節ずつ伸ばせます。範囲は 1 文節〜全文節）。採用範囲から外れた文節は薄い色で表示され、縦積みテーマではタグが「文節」に変わります。別の候補を選ぶと範囲は全文節に戻ります。1 文節のみの候補、予測候補、英字候補では範囲の変更は行われません。

### 採用操作
選択状態に応じたキー操作は以下のとおりです。

| 操作 | 未選択時 | 候補選択中 |
|---|---|---|
| 確定キー (無変換キー) | 入力中のかなのまま確定する | 選択中の候補を採用する |
| Enter | 入力中のかなを確定し、アプリへ Enter を送る | 選択中の候補を採用し、アプリへ Enter を送る |
| 印字キー (文字・数字の入力) | 続けて文字を入力する | 選択中の候補を採用し、その文字から入力を続ける |
| Space | かなを確定してスペースを入力する | 選択中の候補を採用してスペースを入力する |
| `Ctrl + 1`〜`Ctrl + 9` | その番号の候補を採用する | その番号の候補を採用する |

- **番号での採用**: `Ctrl + 数字キー` は確定キーと同じく候補を採用して入力を終えます。採用範囲を縮めていても、候補全体を採用します。表示されているページに無い番号を押したときは何も起きません。候補バーが出ている間は、アプリの `Ctrl + 数字キー`（ブラウザのタブ切り替えなど）より候補の採用が優先されます。

- **採用時の挙動**: 全体変換候補や予測候補を採用すると、入力中のかな全体が候補の文字列に置き換わります。全体変換候補の採用時は、入力末尾の未完成なローマ字（`k` など）はそのまま残りますが、予測候補の採用時は未完成ローマ字は破棄されます（例: `arigat` で「ありがとう」を採用した場合、末尾の `t` は残りません）。
- **縮めた範囲の採用**: 採用範囲を縮めた全体変換候補を確定キーまたは文字入力キーで採用した場合、採用範囲内の文節のみが確定して文書に挿入され、残りのかなは引き続き入力中として維持されます。このとき、候補バーは確定した文節を前文脈として再構築されます。Enter や Space で採用した場合は、採用範囲の文節を確定した上で、残りのかなも確定して入力セッションを終了します。
- **確定アンドゥ**: 確定アンドゥ (`Ctrl + Backspace`) は入力完了後に機能し、最後に採用した文字列（または確定したかな）を入力中の状態に戻します。
- **学習の削除**: 候補を選択している間に `Ctrl + Delete` を押すと、その候補の学習データが削除されます（詳細は [学習の削除](learning.md#学習の削除) を参照してください）。

### 設定とカスタマイズ
- **候補バーの有効/無効**: `candidate_bar` (設定ツールの「候補バーを表示する」、既定値 `1`)。`0` に設定すると候補バーが表示されなくなり、入力中の `Tab` や `↑` `↓` はアプリへ直接渡されます。
- **表示を始める文字数**: `min_suggest_chars` (設定ツールの「候補バー」ページの「表示を始める文字数」、`1`〜`5`、既定値 `2`) でバーが表示される最小文字数を変更できます。
- **予測のオン/オフ**: `suggest` (設定ツールの「入力中に予測を表示する」、既定値 `1`) を `0` にすると、予測候補のみが表示されなくなります（全体変換候補は引き続き表示されます）。
- **テーマ（見た目）**: `panel_theme` (設定ツールの「見た目」ページの「入力パネルのテーマ」、既定値 `capsule`)。組み込みの `capsule` (カプセル 横一列)、`capsule-column` (カプセル 縦積み)、`capsule-blur` (カプセル ぼかし)、`ghost` (ゴースト) から選択するか、テーマフォルダ (`%APPDATA%\QuicklIME\themes\`) に配置したカスタムテーマファイル (`<名前>.tsv`) を指定できます。詳細は [入力パネルのテーマ](theme.md) を参照してください。
- **表示位置**: `candidate_position` (設定ツールの「候補バー」ページの「表示位置」、`caret` / `center`、既定値 `caret`)。`center` に設定すると、候補バーや次の語の予測がキャレットのある画面中央に固定幅で表示されます。変換キーによる候補一覧もこの設定に従います。
- **入力行の表示**: `panel_input` (設定ツールの「入力」ページ「入力中の読み」の「文書と入力パネルの両方に出す」、既定値 `0`)。`1` に設定すると、候補バーの上部に入力中のかな（下線付き）と未完成ローマ字が表示されます。候補が表示されていない場合でも入力行が表示されます。
- **背景のぼかし**: テーマの `blur` 設定が `on` の場合（組み込みの `capsule-blur` など）、入力パネルの背景がアクリル調のすりガラス効果になります（Windows の透明効果が有効な場合のみ機能します）。

## 次の語の予測

確定キーで入力を終了した直後、次の文字を入力する前に、直前の語に続きそうな単語を候補バーに自動表示します。直前の語に続けて確定した履歴のある単語を先に、日本語版ウィキペディアの文章で直前の語に続くことの多い単語をその後ろに並べるため、履歴が無いときも候補が出ます。

- **表示される条件**: 確定キーで入力を終了したとき、または候補バーの採用で残りのかなが無くなって入力が完了したとき、あるいは「次の語の予測」候補を確定キーで採用したとき（続けてさらにその次の語が表示されます）。
- **表示されない条件**: Space や Enter、アプリへ直接渡るキーで入力を終えたとき、直前の文脈がないとき、予測候補が存在しないとき、または設定 `candidate_bar` や `next_word` が `0` のとき。
- **表示位置と見た目**: 通常の候補バーと同じスタイルで表示されます。採用するまで文書の内容は変更されません。
- **予測候補が消える条件**: 候補を選択していない状態で文字キーや移動キーなどを押したとき、候補を選択しないまま設定 `next_word_timeout` の秒数（既定 5 秒）がたったとき、キャレットの移動、入力パネルの外でのマウスクリック、フォーカスの移動、IME をオフにしたとき。
- **候補の選択**: `Ctrl + ↓` (`key.next_word_next`) で先頭候補、`Ctrl + ↑` (`key.next_word_prev`) で末尾候補を選択できます。選択後は通常の候補バーと同様に `Tab` / `↓`、`Shift + Tab` / `↑` で自由に移動できます。
- **番号での採用**: `Ctrl + 1`〜`Ctrl + 9` で、選択していなくてもその番号の候補を文書に入力し、続けてさらに次の語の予測を表示します。予測が表示されている間は、アプリの `Ctrl + 数字キー` より優先されます。

### 採用操作 (選択中)

| 操作 | 動作 |
|---|---|
| 確定キー (無変換キー) | 候補を文書に入力し、続けてさらに次の語の予測を表示する |
| Enter | 候補を文書に入力し、アプリへ Enter を送る |
| Space | 候補を文書に入力し、スペースを挿入する |
| 印字キー (文字・数字の入力) | 候補を文書に入力し、そのキーから新しい入力を開始する |
| Esc | 選択を解除し、予測表示を消去する |
| 変換キーなどその他のキー | 予測表示を消去し、キーに応じた通常の操作を行う |

- **入力の反映と学習**: 候補は既存の文字列を上書きせず追記として挿入されます。採用された単語は学習され、次の予測の前文脈として利用されます。確定アンドゥ (`Ctrl + Backspace`) で取り消すことも可能です。
- **設定**: `next_word` (設定ツールの「確定の後に次の語を予測する」、既定値 `1`)。`0` にすると「次の語の予測」機能が無効になります（入力中の予測候補における文脈順位付けには影響しません）。

## 入力モードの一時表示 (mode_popup)

IME のオン/オフを切り替えたとき（キー操作やタスクバーアイコンのクリック）や、別の入力欄へフォーカスが移動したとき（アプリの切り替えを含む）に、キャレット行のすぐ下に現在の入力モード（日本語入力オン時は「あ」、オフ時は「A」）を示す小さなポップアップが約 1 秒間表示されます。

- **外観**: 入力パネルのテーマ（背景色・枠線・文字色）に合わせて表示されます。作業領域の下端からはみ出る場合は、キャレット行の上に表示されます。
- **自動消去**: 1 秒が経過する前でも、キー入力、フォーカスの移動、入力パネルの表示などが発生すると即座に消去されます。
- **表示されない場合**: 同一の入力欄にフォーカスが戻っただけの場合、入力欄以外の場所にフォーカスがある場合、キャレットの位置が取得できない場合などは表示されません。
- **フォーカスとクリック**: このポップアップはフォーカスを奪わず、ポップアップ上をクリックしても背後のアプリにクリックがそのまま届きます。
- **設定**: `mode_popup` (設定ツールの「見た目」ページ「オン/オフの切り替え時に「あ」「A」を表示する」、既定値 `1`)。`0` に設定するとポップアップ表示を無効化できます。この設定は、オン/オフの切り替え時と、別の入力欄へフォーカスが移動したときの両方の表示に効きます。
