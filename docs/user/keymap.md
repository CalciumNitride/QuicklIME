# キー割当

各機能へのキーの割り当ては、設定ツールの「キー割当」ページ、または `config.tsv` を直接編集することでカスタマイズできます。1 つの機能に複数のキーを割り当てたり、入力状態ごとに割り当てを個別に上書きしたりすることが可能です。

## 設定ツールでの操作

機能ごとに 1 枚のカードが並びます。閉じたカードには機能名・動作する状態・割り当てたキーが表示されます。カードをクリックして開くと、次の操作ができます。

- **キーの追加**: **[+ キーを追加]** を押してから、割り当てるキーを押します。割り当てられないキーや、同じ状態で別の機能に使っているキーは追加されず、理由が表示されます。`Esc` か **[キャンセル]** で取り込みをやめます。
- **キーの削除**: キーの `×` を押します。
- **状態ごとに変える**: オンにすると、その機能が動作する状態ごとにキーを割り当てられます（下記の「状態別の上書き」）。オフに戻すと状態ごとの割り当ては消えます。
- **[既定に戻す]**: その機能の割り当てを既定に戻します。ページ上部の **[すべて既定に戻す]** は全機能を既定に戻します。

変更はすぐに設定ファイル (`config.tsv`) に保存されます。同じ状態で同じキーを使っている機能があれば、ページ上部に警告が表示されます（設定ツールを開いたときと、割り当てを変えるたびに調べ直します）。

## 機能と既定のキー割当

| 機能 | 設定キー | 動作する状態 | 既定のキー |
|---|---|---|---|
| 変換 | `key.convert` | 全状態 | `Convert` (変換) |
| 次候補 | `key.next_candidate` | 候補選択中 | `Space` |
| 前候補 | `key.prev_candidate` | 候補選択中 | `Shift+Space` |
| 確定 | `key.commit_run` | 入力中・候補選択中・予測選択中 | `NonConvert` (無変換) |
| 記号・日付変換 | `key.convert_symbol` | 同上 | `F4` |
| ユーザー語変換 | `key.convert_user` | 同上 | `F5` |
| ひらがな変換 | `key.to_hiragana` | 全状態 | `F6` |
| カタカナ変換 | `key.to_katakana` | 同上 | `F7` |
| 半角カタカナ変換 | `key.to_half_katakana` | 同上 | `F8` |
| 全角英字変換 | `key.to_full_ascii` | 同上 | `F9` |
| 半角英字変換 | `key.to_half_ascii` | 同上 | `F10` |
| 確定アンドゥ | `key.undo_commit` | 入力なし | `Ctrl+Backspace` |
| 単語登録 | `key.register_word` | 入力なし | `Ctrl+F7` |
| 設定を開く | `key.open_config` | 入力なし | `Ctrl+F12` |
| 改行 (チャット用) | `key.insert_newline` | 全状態 | `Ctrl+J` |
| 次の語の予測: 次へ | `key.next_word_next` | 入力なし・予測選択中 | `Ctrl+Down` |
| 次の語の予測: 前へ | `key.next_word_prev` | 同上 | `Ctrl+Up` |
| 学習の削除 | `key.forget_learning` | 予測選択中 | `Ctrl+Delete` |

### 状態の区分
- **入力なし (`idle`)**: 読みを入力していない待機状態です。
- **入力中 (`run`)**: 未確定の読みを入力している状態です。
- **候補選択中 (`candidate`)**: 変換キーなどで候補一覧を表示し、候補を選んでいる状態です。
- **予測選択中 (`suggest`)**: 候補バーまたは「次の語の予測」で候補を選んでいる状態です。

## config.tsv でのカスタマイズ書式

`config.tsv` に記述する場合の書式は以下のとおりです。

- **基本の割当**: `key.<機能名><TAB><キー>[,<キー>...]`  
  （例: `key.convert	Convert,Ctrl+Space`）
- **状態別の上書き**: `key.<機能名>@<状態><TAB><キー>[,<キー>...]`  
  （例: `key.commit_run@candidate	Ctrl+Enter`）  
  ※状態別の上書きを指定した場合、その状態では基本の割当は使われず、上書きされたキーのみが有効になります。
- **割り当ての解除**: キー名に `none` を指定すると、その機能へのキー割り当てを解除できます（例: `key.next_candidate@candidate	none`）。

### キーの表記方法
修飾キー（`Ctrl+`、`Shift+`）を先頭に付け、続けてキー名を指定します。
- **英数字・ファンクションキー**: `A`〜`Z`、`0`〜`9`、`F1`〜`F24`
- **特殊キー**: `Space`、`Enter`、`Esc`、`Tab`、`Backspace`、`Delete`、`Insert`、`Home`、`End`、`PageUp`、`PageDown`、`Up`、`Down`、`Left`、`Right`
- **日本語キー**: `Convert`（変換）、`NonConvert`（無変換）、`Kana`（カタカナ/ひらがな）
- **上記以外**: `VK_xx`（16 進数 2 桁の仮想キーコード）

### 割り当てに関するルールと注意点
- **割り当てられないキー**:
  - 修飾キーなし、または `Shift` のみの標準的な編集キー（Enter、Esc、Tab、Backspace、Delete、矢印キー、Home、End、PageUp、PageDown）
  - 通常の文字入力キー（英字、数字、記号、テンキー）
  - `Ctrl + M`、`Ctrl + H`
  - `Ctrl + 1`〜`Ctrl + 9`（候補の番号での採用・確定に使うため。`Ctrl + Shift + 数字` と `Ctrl + 0` は割り当て可能）
  - IME 切り替えキー（半角/全角キーなど）
  - 修飾キー単体、`Alt` 併用キー（アプリによって IME に届かない場合があるため）、`Win` 併用キー
  ※`Ctrl` 併用のキー（`Ctrl + Enter` など）や `Space`、`変換`、`無変換`、ファンクションキーは自由に割り当て可能です。不正なキー名や割り当て不可のキーが記述された場合は無視されます。
- **キーの重複**: 同じ状態で複数の機能に同じキーが割り当てられている場合は、状態別の上書きが優先され、それでも重複する場合は表の上位にある機能が優先されます（設定ツールでは、同じ状態で別の機能に使っているキーは追加できません）。
- **変換キーと Shift**: 「変換」に割り当てたキーは、`Shift` を付加した入力（候補選択中の前候補）にも連動します。`Shift` 併用のキーに別の機能を割り当てている場合は、その機能が優先されます。
- **未処理キーの動作**: 割り当てに一致しないキーは、IME がそのキーに決めている動作（Space ならスペースの入力、矢印なら入力の確定とキャレットの移動など）になり、決まった動作の無いキーは背後のアプリへ渡されます。その時点で実行できない機能のキー（再変換対象がないときの変換キーなど）は、そのまま背後のアプリへ渡されます。例えば候補選択中の Space の割り当てを外すと、Space キーで候補を確定してスペースが挿入されるようになります。
