# 候補パネルのテーマ

候補バー（入力中のサジェストおよび次の語の予測）と、変換キーで表示される候補一覧の外観は、テーマによって自由にカスタマイズできます。組み込みのテーマから選ぶほか、組み込みテーマをベースにして変更したい項目だけを指定したカスタムテーマファイルを作成することも可能です。

変換キーで表示される候補一覧は、テーマの `layout` 設定にかかわらず常に縦方向に積み重なるリスト形式で表示され、通常は候補種類のタグ (`kind_tag`) は表示されません（ただしミスタイプを補正した候補には、設定によらず「補正」タグが表示されます）。

## テーマの選び方

設定ツールの「表示」タブにある「候補の見た目」(`panel_theme`、既定値 `capsule`) から選択できます。

| テーマ名 | 設定ツールでの表記 | 外観と特徴 |
|---|---|---|
| `capsule` | カプセル (横一列) | 半透明・角丸・影付きのパネルに、丸みのあるチップ状の候補を横一列に並べます |
| `capsule-column` | カプセル (縦積み) | カプセルの配色をベースに候補を縦に並べ、各行の右側に候補種類のタグを表示します |
| `capsule-blur` | カプセル (ぼかし) | `capsule` の背景にアクリル調のすりガラス（ぼかし）効果を適用します |
| `ghost` | ゴースト | 枠線を持たず、大きな文字で入力と最良候補を薄く表示し、その下に番号付きの候補を並べます |

- **カスタムテーマの配置**: `%APPDATA%\QuicklIME\themes\` フォルダ内に `<テーマ名>.tsv` として保存します（設定ツールの「テーマのフォルダを開く」から開くことができます。フォルダが存在しない場合は自動作成されます）。配置したファイルは、「候補の見た目」の一覧に拡張子を除いた名前で表示されます。
- **名前の解決順序**: テーマフォルダ内の `<テーマ名>.tsv` → 同名の組み込みテーマ → いずれも存在しない場合は `capsule` が使用されます。
- 組み込みテーマと同名のファイル（`capsule.tsv` など）を配置した場合は、組み込み設定よりもファイルの内容が優先されます。
- **検証用環境変数**: 環境変数 `QUICKLIME_THEME_DIR` を指定すると、テーマフォルダの場所を変更できます。
- **設定の反映**: ウィンドウフォーカスの移動や IME のオン/オフ切り替え時にテーマファイルの更新時刻がチェックされ、変更があれば自動で再読み込みされます。Windows のアプリモード（ライト/ダーク）の切り替えもこのタイミングで反映されます。

## テーマファイルの書式

`config.tsv` と同様に、UTF-8 のテキストファイルで `キー<TAB>値` の形式で記述します。行頭が `#` の行はコメント行、空行は無視されます。

```
# 例: カプセルを少し角ばらせ、アクセントカラーを緑にする
base	capsule
panel_radius	0.4
chip_shape	rounded
accent	#2E9E6B
dark.background	#101014EE
```

- **`base`**: 土台にする組み込みテーマ名（`capsule` / `capsule-column` / `capsule-blur` / `ghost`）を指定します（省略時は `capsule`）。カスタムテーマを別のカスタムテーマの `base` に指定することはできません。ファイルのどの行に記述しても有効です。
- **設定の優先順序**: 全キーの既定値（`capsule` と同様）→ `base` で指定されたテーマ → テーマファイル内の記述 の順に上書きされ、より後から読み込まれた値が優先されます。同じキーが複数行ある場合は、後の行が優先されます。
- **カラーコード**: `#RRGGBB` または `#RRGGBBAA`（AA は不透明度。`00` で完全透明、`FF` で完全不透明）で指定します。
- **ライト/ダークモード対応**: 色のキーをそのまま書くとライト・ダーク共通の設定となり、`light.` または `dark.` を前置すると該当モードでのみ有効になります。同じファイルに両方が記述されている場合は、記述順序にかかわらず `light.` / `dark.` 付きの指定が優先されます。
- **レイアウト・寸法キー**: 色以外のキー（配置・形状・サイズなど）はライト・ダーク共通です（`light.` や `dark.` は付与できません）。
- **未定義・不正な値**: 未対応のキーや書式が正しくない行は無視され、土台となるテーマの値が維持されます。数値が有効範囲外の場合は自動的に範囲内に丸められます（無視された行や丸められた値は診断ログ `debug_log` に記録されます）。

## キー

### 描き方と並べ方

| キー | 値 | 既定 | 内容 |
|---|---|---|---|
| `style` | `capsule` / `ghost` | `capsule` | 描き方。`capsule` は背景・縁・影のあるパネル。`ghost` は枠を持たず、背景の代わりに放射状のにじみを描き、入力行の後ろに「→ 候補」の形で選択中 (未選択なら先頭) の候補を薄く出す |
| `layout` | `row` / `column` | `row` | 候補を横一列に並べるか、縦に積むか |
| `align` | `left` / `center` | `left` | 入力行と候補の揃え |
| `input_row` | `setting` / `always` | `setting` | `setting` は設定 `panel_input` (「入力中の読みも候補と同じ場所に表示する」) に従う。`always` は設定によらず入力行を出す |
| `blur` | `on` / `off` | `off` | パネルの背景をぼかし (アクリル) にする。Windows の透明効果がオフのときや使えない環境では通常の描画で出る |

### 形

| キー | 値 | 既定 | 内容 |
|---|---|---|---|
| `chip_shape` | `pill` / `rounded` / `underline` | `pill` | 候補の形。`pill` は両端が半円、`rounded` は角丸 (`chip_radius`)、`underline` は背景を持たず、選択中だけ下線を引く |
| `badge_shape` | `circle` / `square` / `plain` / `none` | `circle` | 候補番号の形。`plain` は数字だけ、`none` は番号を出さない (数字キーでの選択はできる) |
| `selection` | `fill` / `soft` / `text` | `fill` | 選択中の候補の強調。`fill` はアクセント色で塗って文字を `selected_text` に、`soft` はアクセント色を薄く敷いて文字をアクセント色に、`text` は文字だけをアクセント色の太字にする |
| `border` | `on` / `off` | `on` | パネルの外周の縁 |
| `shadow` | `on` / `off` | `on` | パネルの影 |
| `kind_tag` | `on` / `off` | `off` | 候補の種類のタグ (英字・変換・補正・予測・文節・次の語)。`layout column` のときだけ効く |
| `text_shadow` | `on` / `off` | `off` | 文字の下に薄い影 (ダークでは黒、ライトでは白) を敷き、下の背景によらず読めるようにする |
| `caret_marker` | `off` / `pointer` / `triangle` | `triangle` | 文書のキャレットの位置を示す印 (下の「キャレットの印」) |

- `border` と `shadow` は色のキーと同じ名前です。値が `on` / `off` であれば形状設定、`#` で始まれば色設定として解釈されます。`caret_marker` も同様に、値が `off` / `pointer` / `triangle` であれば形状設定、`#` で始まれば色設定として解釈されます。
- `layout row`（横一列）で `pill` または `rounded` を指定した場合、未選択の候補も `chip` 色の背景を持ちます。`layout column`（縦積み）では、未選択の行は背景を持たず、選択中の行のみが `selection` 設定に従って強調されます。
- `underline`（下線スタイル）で `selection fill` または `soft` を指定した場合、下線の色のみがアクセントカラーになります。
- 「次の語の予測」の候補は、`layout row` の `pill` / `rounded` において `next_word` 色の枠線が付きます。
- タイポ補正候補（全体変換の補正候補、および入力ミスを補正して検出した予測候補）は、`layout row` の `pill` / `rounded` において `typo` 色の枠線が付きます。
- 採用範囲を縮めた全体変換（[候補バー](candidate-bar.md) 参照）では、採用対象となる文節は通常色、除外される残りの文節は文字色の不透明度 0.5（半透明）で描画されます。

## キャレットの印 (`caret_marker`)

文字の入力中、変換の候補選択中、および「次の語の予測」の表示中に、文書内のキャレット（カーソル）位置を示す視覚的なインジケーターを表示できます。確定、取り消し、フォーカスの移動、IME オフなどのタイミングで自動的に消去されます。

- **キャレット位置の判定**: 文書内に入力中の文字列（composition）がある場合はその末尾、ない場合は選択範囲の先頭（取得できない場合はシステムのキャレット）の位置に合わせます。位置情報が取得できない場合や、ウィンドウ外を指している場合は表示されません。
- **追従**: キー入力時やパネルの再描画時に位置が再取得されます（ウィンドウのドラッグ移動やスクロールには追従しません）。
- **`triangle`（三角マーカー）**: キャレットの下端に、上向きの小さな三角形（`triangle_size`、色 `caret_marker`）を表示します。候補パネルとは独立したレイヤーで描画されるため、パネルの有無や位置にかかわらず表示されます。三角形をクリックしても背後の文書にクリックがそのまま届きます。候補パネルをキャレット行の下に表示する場合は、三角形の高さ分だけパネルの表示位置が下がります。
- **`pointer`（吹き出しのポインター）**: 候補パネル（候補バーおよび候補一覧）の縁に、キャレットを指し示す吹き出し状の突起（`pointer_size`）を付加します。パネルがキャレット行の下にある場合は上辺に、上にある場合は下辺に付きます。画面中央配置 (`candidate_position center`) や `ghost` スタイル、アクリルぼかし (`blur on`) 有効時などはポインターは表示されません。
- **ぼかしとの組み合わせ**: `blur on` と `caret_marker pointer` を同一テーマに指定した場合はぼかしが優先され、ポインター突起は描画されません（Windows の透明効果が無効で通常描画になる環境ではポインターが表示されます）。
- **点滅**: マーカーは点滅せず、常に安定して表示されます。

## 縦積み (`layout column`)

## 縦積み (`layout column`)

- **レイアウト**: 1 行ごとに番号・候補・種類のタグ（`kind_tag on` のとき右端）を並べて表示します。各行の高さは `chip_height` で設定します。
- **表示件数とページ送り**: 1 ページあたり最大 9 行表示されます。画面の作業領域に収まらない場合は収まる行数に自動調整され、残りはページ送りで表示されます。複数ページある場合は最終行の下に現在位置（例: `12/24`）が表示されます。
- **操作方法**: 横一列表示と同様に、`Tab` / `↓` で次候補、`Shift + Tab` / `↑` で前候補、数字キーで直接選択が可能です（横一列と異なり、`←` / `→` では選択候補は移動しません）。
- **キャレットの下に表示する場合 (`candidate_position caret`)**: パネルの幅は最も横幅が広い行に合わせて自動調整されます（画面幅が上限）。上下位置は最大 9 行分と位置表示の高さに基づいて計算され、画面下端に収まらない場合はキャレット行の上側に下端を揃えて表示されます。上側に表示される際は並び順が反転し、キャレットに近い側から「入力行・候補 1, 2, 3…・位置表示」の順に積まれます（このとき `↑` で次候補、`↓` で前候補に進みます）。
- **画面中央に表示する場合 (`candidate_position center`)**: 横一列テーマと同様の固定幅で画面中央に表示されます。
- **文字あふれ**: パネル幅に収まらない長い行は、末尾が「…」で省略されます。

## ゴースト (`style ghost`)

- **インライン候補表示**: 入力行の文字サイズが `ghost_text_size` で大きく描画され、入力中のかな・未完成ローマ字・キャレットに続いて「→ 候補」の形式で最良候補が薄く表示されます（`text` 色、不透明度 `ghost_opacity`）。`Tab` キーなどで候補を選択すると、選んだ候補の内容に切り替わります。
- **次の語の予測**: 直前の確定テキストおよび「次の語」ラベルに続けて同様に薄く表示されます。
- **候補一覧**: 入力行の直下に枠線なしで番号付きの候補が並びます。
- **中央揃え (`align center`)**: 入力行と候補がパネルの中央揃えで配置されます。

## 組み込みテーマの値

`capsule` は上の表の既定値そのもの (`style capsule`・`layout row`・`align left`・`input_row setting`・
`blur off`・`chip_shape pill`・`badge_shape circle`・`selection fill`・`border on`・`shadow on`・
`kind_tag off`・`text_shadow off`・`caret_marker triangle`)。`capsule-column`・`capsule-blur`・`ghost` も
`caret_marker` を `capsule` から受け継ぐ (`triangle`)。

`capsule-column` (`base capsule` に次を重ねる):

```
layout	column
panel_radius	0.7
chip_shape	rounded
chip_height	1.7
badge_shape	square
selection	soft
kind_tag	on
```

`capsule-blur` (`base capsule` に次を重ねる):

```
blur	on
```

`ghost` (`base capsule` に次を重ねる):

```
style	ghost
align	center
input_row	always
blur	off
chip_shape	underline
badge_shape	plain
selection	text
border	off
shadow	off
text_shadow	on
```

## 例

縦積みで、番号を出さず、選択を塗りつぶしにする:

```
base	capsule-column
badge_shape	none
selection	fill
```
