# 設定一覧

QuicklIME の設定は、設定ツール（`Ctrl + F12`、またはタスクバーの通知領域にある入力モードアイコンの右クリックメニュー「設定...」）から変更できます。設定内容は `%APPDATA%\QuicklIME\config.tsv` (UTF-8) に自動保存されます。テキストエディタで直接編集することも可能です。

- **設定ファイルの書式**: 1 行 1 項目の `キー<TAB>値` です。行頭が `#` の行はコメント行として扱われます。
- **未定義・不正な値の扱い**: 未対応のキーは無視され、不正な値が指定されたキーは自動的に既定値として処理されます。
- **設定ツールでの書き出し**: 設定ツールには保存のボタンがありません。値を変えると、約 0.3 秒後に全設定項目がファイルに書き出されます（`debug_log` は値が設定されている場合のみ）。書き込めなかった場合は、設定ツールの上部にエラーが表示されます。
- **設定の反映**: 起動中のアプリには、ウィンドウフォーカスの移動や IME のオン/オフ切り替えのタイミングで自動的に再読み込みされ、即座に反映されます（アプリの再起動は不要です）。設定ツールで値を変えてアプリに戻る操作自体がフォーカス移動になるため、すぐに反映されます。

## 設定キー一覧

| キー | 設定ツールでの表記 (ページ) | 設定可能な値 | 既定値 | 詳細説明 |
|---|---|---|---|---|
| `learning` | 学習する (変換) | `0` / `1`（`0` にすると新しい確定・採用を学習しません。既存の学習データは維持されます） | `1` | [学習](learning.md) |
| `suggest` | 入力中に予測を表示する (候補バー) | `0` / `1`（`0` にすると候補バーに予測候補や次の語の予測を表示しません。全体変換は表示されます） | `1` | [候補バー](candidate-bar.md) |
| `typo_correction` | タイプミス補正 (変換) | `0` / `1`（`0` にすると打ち間違いを補正した候補を表示しません） | `1` | [入力と変換](input.md) |
| `max_predictions` | 件数 (候補バー) | `9` / `18` / `27` / `36`（候補バーに表示する候補の最大件数） | `9` | [候補バー](candidate-bar.md) |
| `min_suggest_chars` | 表示を始める文字数 (候補バー) | `1`〜`5`（候補バーを表示する最小のかな文字数） | `2` | [候補バー](candidate-bar.md) |
| `segment_ui` | 文節単位で変換する (変換) | `0` / `1`（`1` にすると従来の一般的な IME のように文節ごとに変換します） | `0` | [入力と変換](input.md) |
| `llm` | AI で候補を並べ替える (変換) | `0` / `1`（`1` にすると AI モデルで候補を文脈順に並べ替えます） | `0` | [AI による候補の並べ替え](llm.md) |
| `llm_backend` | AI で候補を並べ替える の「実行環境」 (変換) | `cpu` (CPU) / `vulkan` (GPU (Vulkan)) | `cpu` | [AI による候補の並べ替え](llm.md) |
| `space` | スペース (入力) | `full` (全角スペース) / `half` (半角スペース) | `full` | この表 |
| `punctuation` | 句読点 (入力) | `、。` / `，．` / `、．` / `，。` | `、。` | この表 |
| `digits` | 数字 (入力) | `half` (半角) / `full` (全角) | `half` | この表 |
| `modeless` | モードレス入力 (入力) | `0` / `1`（`1` にすると IME をオフにせず英単語を入力できます） | `0` | [モードレス入力](modeless.md) |
| `input_buffer` | 入力中の読み (入力) | `composition` (文書に下線付きで出す・文書と入力パネルの両方に出す) / `panel` (入力パネルだけに出す) | `composition` | [入力と変換 (input_buffer)](input.md#入力中の読みの表示-input_buffer) |
| `input_scope_passthrough` | 数字やメールアドレスの欄では日本語入力を使わない (入力) | `0` / `1`（`1` にすると半角専用欄で自動的に直接入力になります） | `1` | [入力と変換 (input_scope_passthrough)](input.md#数字メールアドレスなどの入力欄-input_scope_passthrough) |
| `candidate_bar` | 候補バーを表示する (候補バー) | `0` / `1`（`0` にすると候補バーを表示しません） | `1` | [候補バー](candidate-bar.md) |
| `next_word` | 確定の後に次の語を予測する (候補バー) | `0` / `1`（`0` にすると確定後の次の語の予測を表示しません） | `1` | [次の語の予測](candidate-bar.md#次の語の予測) |
| `panel_theme` | 入力パネルのテーマ (見た目) | `capsule` / `capsule-column` / `capsule-blur` / `ghost`、またはカスタムテーマ名 | `capsule` | [候補バー](candidate-bar.md)・[入力パネルのテーマ](theme.md) |
| `candidate_position` | 表示位置 (候補バー) | `caret` (キャレットの下) / `center` (画面中央) | `caret` | [候補バー](candidate-bar.md) |
| `panel_input` | 入力中の読み (入力) の「文書と入力パネルの両方に出す」 | `0` / `1`（`1` にすると入力パネル上部に入力行を表示します。`input_buffer panel` のときは効きません） | `0` | [候補バー](candidate-bar.md)・[入力と変換 (input_buffer)](input.md#入力中の読みの表示-input_buffer) |
| `mode_popup` | オン/オフの切り替え時に「あ」「A」を表示する (見た目) | `0` / `1`（`1` にすると IME 切り替え時にモードを一時表示します） | `1` | [入力モードの一時表示](candidate-bar.md#入力モードの一時表示-mode_popup) |
| `candidate_font` | フォント (見た目) | 入力パネルのフォント名（31 文字まで） | `Yu Gothic UI` | この表 |
| `candidate_font_size` | サイズ (見た目) | `10`〜`40`（入力パネルのフォントサイズ px） | `18` | この表 |
| `key.*` | 機能ごとのカード (キー割当) | 各機能に割り当てるキー設定 | 機能別に設定 | [キー割当](keymap.md) |
| `newline_apps` | 改行キーで Shift+Enter を送る (アプリ) | 対象アプリの exe 名（カンマ区切り） | `Discord.exe,slack.exe,ms-teams.exe,Teams.exe,LINE.exe` | [アプリごとの設定](app-settings.md)・[入力と変換](input.md) |
| `ime_start_apps` | 起動時の IME (アプリ) | `exe名:on` / `exe名:off`（カンマ区切り） | 空（自動） | [アプリごとの設定](app-settings.md) |
| `no_learning_apps` | このアプリでは学習しない (アプリ) | 対象アプリの exe 名（カンマ区切り） | 空（全アプリで学習） | [学習](learning.md#学習しないアプリ-no_learning_apps) |
| `debug_log` | 診断ログを出力する・診断ログの出力先 (詳細) | 診断ログファイルの出力先パス（不具合調査用） | 空（出力しない） | この表 |
