# 学習

## 確定・採用での学習

- **確定や採用による学習**: 候補の確定時や候補バーからの採用時に、選択した表記や文脈が自動的に学習されます。2文節以上の変換結果を確定・採用したときは読み全体の表記も学習され、次回以降に同じ読みを入力した際に、その表記が変換候補の先頭や予測候補に優先して表示されます。
- **使用頻度と新しさの反映**: 学習は確定した回数（使用頻度）に応じて効果を発揮します。ある文節で確定した単語は、別の文の変換時にも選ばれやすくなります（例:「今日は」を確定した後は「きょうも」の変換で「今日も」が優先されます）。よく使う表記がある場合、一度だけ別の表記を選んでも即座に入れ替わることはありません。また、使わなくなった古い学習内容は確定を重ねるにつれて効果が薄れていきます。詳しい仕様は [learning-score.md](../design/learning-score.md)（設計書）を参照してください。

## 学習の削除

候補を選択している間（「次の語の予測」を含む）に `Ctrl + Delete` (`key.forget_learning`) を押すと、選択中の候補に関する学習データ（確定履歴、直前の語に続けて確定した履歴、構成単語の学習など）を削除し、候補一覧を再構築します。

- 選択位置は同じ番号の候補が維持されます（候補数が減って選択位置が存在しなくなった場合は末尾の候補が選択されます）。
- 全体変換候補の場合は、文節ごとの学習のうち表記が一致するものも削除されます。
- システム同梱の辞書やユーザー辞書の登録単語、英字候補などは削除されません（キーを押しても何も起きず、そのまま操作を続けられます）。
- 文書内のテキストには影響しません。
- 設定 `learning` を `0`（学習無効）にしている場合でも、既存の学習履歴を削除できます。

## 学習しないアプリ (no_learning_apps)

特定のアプリ（ターミナルやパスワード管理ツールなど）での入力内容を学習させたくない場合は、設定 `no_learning_apps` で学習を無効化できます。

- **設定値**: アプリの実行ファイル名（exe 名）をカンマ区切りで指定します（例: `WindowsTerminal.exe,wezterm-gui.exe`。大文字と小文字は区別されません）。
- **既定値**: 空（すべてのアプリで学習します）。
- **設定方法**: 設定ツールの「アプリ」タブ ([アプリごとの設定](app-settings.md)) から追加・変更できます。

### 動作の補足
- 対象アプリで無効化されるのは「新しい学習の記録」のみです。すでに保存されている既存の学習データは、対象アプリでの入力時にも候補の優先順位付けに利用されます。
- 単語登録ツールによる登録は停止されません。
- 直前に確定した文節（前文脈）は、対象アプリ内でも後続語の予測や文脈補正のために一時的に使用されます。
- 設定を変更すると、フォーカス移動時などの設定再読み込みによって、現在起動中のアプリにもすぐに反映されます。
