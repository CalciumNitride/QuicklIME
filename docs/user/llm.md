# AI による候補の並べ替え

設定 `llm`（設定ツールの「AI で候補を並べ替える」、既定値 `0`）を `1` にすると、かな漢字変換モデル（zenz）を利用して、前後の文脈に最も適した候補が上位になるよう自動的に並べ替えます。

## 特徴と動作の流れ

- **高速で快適なレスポンス**: 候補バーにはまず従来の統計的変換による候補が即座に表示され、AI による並べ替え処理が完了した段階（通常は数十ミリ秒以内）で最適な並び順へと自然に更新されます。キー入力の引っかかりや遅延は発生しません。また、候補バーで候補を選択している最中や変換候補一覧の操作中には、意図しない誤選択を防ぐため候補の並び順は固定されます。
- **変換キーへの反映**: 変換キーを押した時点で AI による並べ替えが完了していれば、縦の候補一覧にも並べ替え後の最適な順序が反映されます。
- **文脈情報の取り扱いとプライバシー**: 入力開始位置より前の同じ行にあるテキストを前文脈として参照します（読める文書では文書内のテキストを参照し、ターミナル等の未判定文書では IME が直前に入力した文字列をメモリ上で一時保持して利用します）。文脈情報は推論処理のためだけにメモリ上でのみ使用され、ログファイルへの出力や外部サーバーへの送信は一切行われません。なお、Enter による改行、キャレットの移動、フォーカスの切り替えなどで文脈情報は安全に破棄されます（詳細は [読める文書](input.md#読める文書) を参照してください）。
- **並べ替える読みの長さ**: 並べ替えは 9 文字以上の読みでだけ行います。短い読みでは従来の統計的変換の順位のほうが当たりやすいため、8 文字以下の読みは従来の並び順のまま表示されます。
- **固定される候補**: 並べ替えの対象となるのは変換結果の上位 10 件です。ユーザーが頻繁に使って学習された表記、ユーザー辞書の登録単語、英字を含む候補、数字表記の候補、タイポ補正候補などは、意図した入力を妨げないよう元の位置が維持されます。
- **候補の生成（GPU (Vulkan) のみ）**: `llm_backend` が `vulkan` で GPU 版が動いているときは、長めの読み（9 文字以上）で、並べ替えに加えて AI が読みから変換結果を 1 件生成し、候補に加えます。従来の変換候補に無い表記も、候補バーと変換キーの候補一覧に出ます。CPU 版（GPU 版が使えず CPU 版で動いているときを含む）では生成しません。

## 実行環境の設定 (`llm_backend`)

設定ツールの「AI で候補を並べ替える」を開いて出る「実行環境」(`llm_backend`) で、推論を実行するバックエンドを選択できます。

- **`cpu`（既定値）**: 軽量モデル（`zenz-v3.2-xsmall`）を CPU 上で動作させます。特別な GPU 環境を必要とせず、安定して動作します。
- **`vulkan`**: GPU を活用したモデル（`zenz-v3.2-small`）で動作します。グラフィックボードを搭載した PC で高速な推論が可能で、並べ替えに加えて候補の生成も行います（Vulkan が利用できない環境では自動的に CPU 版へフォールバックし、その間は生成しません）。

## 安定性とフォールバック
推論処理は独立したバックグラウンドプロセス (`quicklime-llm.exe` / `quicklime-llm-vulkan.exe`) で安全に行われます。モデル読み込み中や、推論プロセスの応答が遅れた場合、あるいは万が一推論プロセスが動作しない場合でも、通常の統計的変換エンジンによって途切れることなく普段どおりの日本語入力を行えます。
