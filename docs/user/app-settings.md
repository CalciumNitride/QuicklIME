# アプリごとの設定

設定ツールの「アプリ」ページでは、アプリケーション（実行ファイル名 / exe 名）ごとに個別の動作を設定できます。

アプリは 1 つずつカードで並びます。閉じたカードには exe 名と、既定から変えた設定の要約（例: `改行キーで Shift+Enter`、`起動時の IME: オフ・学習しない`）が表示されます。

## 設定ツールの操作方法

1. **アプリの追加**:
   - **[実行中のアプリから追加]**: 現在画面上にウィンドウが表示されているアプリの一覧から選択して追加します。
   - **[exe を選ぶ]**: 目的の exe ファイルを直接選択して追加します。
   - 追加されたアプリは、初期状態として「改行キーなし・自動・学習する」に設定されます。
2. **設定の編集**: カードをクリックして開くと、次の項目を変更できます。
   - **改行キーで Shift+Enter を送る** (`newline_apps`)
   - **起動時の IME** (`ime_start_apps`): `自動` / `オン` / `オフ`
   - **このアプリでは学習しない** (`no_learning_apps`)
3. **削除**: 開いたカードの **[一覧から外す]** で、そのアプリの設定を一覧から削除します。

変更はすぐに設定ファイル (`config.tsv`) に保存されます。

## 各設定項目の詳細

### 起動時の IME 状態 (`ime_start_apps`)
アプリ起動時に、IME を「日本語入力オン」で開始するか「オフ」で開始するかをアプリごとに指定できます。

- **書式**: `exe名:on` または `exe名:off` をカンマ区切りで指定（例: `Notepad.exe:on,WindowsTerminal.exe:off`。大文字と小文字は区別されません）。既定値は空です。
- **「自動」の動作**: 一覧にないアプリ、または「自動」に設定されたアプリでは、IME のオン/オフはアプリや Windows システムの既定動作に委ねられます。
- **適用のタイミング**: そのプロセスのウィンドウで最初にテキスト入力フォーカスを取得した 1 回のみ適用されます。作業中にアプリ内で手動切り替えしたオン/オフ状態を勝手に上書きすることはありません。設定変更は、次回新しく起動したアプリから有効になります。

### 改行キー (`newline_apps`)
チャットアプリなどで、Enter キーによる意図しないメッセージ送信を防ぎ、`Ctrl + J`（または割り当てた改行キー）で `Shift + Enter` を送って改行できるようにします。詳細は [入力と変換 (Ctrl+J)](input.md) を参照してください。

### 学習の停止 (`no_learning_apps`)
ターミナルや機密情報を扱うアプリで入力履歴を学習させたくない場合に設定します。設定値や詳細な挙動については [学習しないアプリ](learning.md#学習しないアプリ-no_learning_apps) を参照してください。
