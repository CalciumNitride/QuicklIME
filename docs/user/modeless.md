# モードレス入力 (modeless)

設定 `modeless`（設定ツールの「モードレス入力」、既定値 `0` (OFF)）を `1` (ON) にすると、英語のタイピングを IME が自動的に判別し、アルファベットのまま直接入力できるようになります。`半角/全角` キーなどでいちいち IME をオフに切り替えることなく、日本語と英語をスムーズに混在して入力できます（IME 自体のオン/オフ機能も従来どおり併用可能です）。

自動判定が成立すると、入力中の文字列のうち英単語に該当する部分だけが「英字区間」へと自動的に切り替わります。それより前に入力されていた日本語部分はそのまま維持されます（例: `kyouhagithu` と入力すると「きょうは」の後に `githu` が続き、`apple` と打つと「あっp」から「appl」へと切り替わります）。

## 打鍵中に英字になる場合

以下の綴りが入力されたタイミングで、自動的に英字入力へと切り替わります。

- **ローマ字として成立しない子音の連続**: 英語特有の子音並び（`apple` の `pl`、`str` など）が現れたとき。
- **促音の直後に小書き母音が入力された場合**: `hello` の入力（「へっ」＋「ぉ」）など。
- **`c` の直後に母音が続く綴り**: `ca` `ci` `cu` `ce` `co`（※ローマ字設定で c 行を「か」などに割り当てている場合のみ判定されます）。
- **`th` を含む特定の綴り**: `tha` `thu` `the` `tho`（`github`、`the`、`method` など。外来語表記で使われる `thi` は除きます）。

前者の英語特有の綴りは、英単語辞書に未登録の単語であっても即座に英字に切り替わります。後者のローマ字としても読める綴りは、内蔵の英単語辞書と一致した場合にのみ英字に切り替わります。

### 単語の開始判定
英単語の開始位置が確定するまでは、一時的にローマ字の未完成入力のまま待機し、単語であることが確認された時点で英字に切り替わります（例: `kyouhacamera` では、`kyouhaca` までは「きょうは」＋未完成の `ca` として保持され、`cam` まで打った時点で「きょうはcam」へと切り替わります）。

自動判定によって英字になった後、誤判定だった場合でも Backspace キーで判定のきっかけとなった文字まで削除すれば、元の日本語入力の状態に自然に戻ります。

## run を終えたら英字になる形 (英字候補)

入力を確定する段階で強制的に英字へ書き換えてしまうことはなく、どのキーで確定しても画面に見えているとおりの内容で確定されます（例: `kyouhawant` と入力して Space を押した場合は「きょうはわんt」となります）。

その代わり、現在の入力のまま確定したときに英字になる表記が、タイピング中に**候補バーの先頭に「英字候補」**として常に提示されます。`Tab` キーなどで英字候補を選択して `Space` を押せば「英単語＋半角スペース」、確定キーや `Enter` で確定すれば「英単語のみ」を入力できます。

- **末尾に 1 文字の未完成子音が残っている場合**: `kyouhawant` と入力すると、候補バーの先頭に英字候補「きょうはwant」が表示されます。
- **英文の途中の単語**: 直前に確定した文字列が半角英字で終わっている場合、続く入力も英単語辞書と照合して英字候補を提示します（例: `GitHub no` のように助詞が続く場合は日本語の「の」が優先されます）。
- **日本語として使われることがほぼない英単語**: `remote` や `feature` など、ローマ字としても読めるものの日本語の単語としては使われない語は、入力中に英字候補が提示されます（例: `korehafeature` → 「これはfeature」）。

候補バーに出ない単語を英字にしたいときは、確定前に `F10` キーを押すことで、手動で半角英字に変換できます（`F10` の後に `←` `→` を押すことで英字化する範囲の微調整も可能です）。

## 直し方

英字と日本語の区切り位置が意図と異なってしまった場合は、ファンクションキー（`F10` で半角英字、`F6` でひらがな）で入力全体を希望の文字種に修正できます。

また、`Backspace` キーで英字区間の文字をすべて消去すれば、英字モードが解除され、直前の日本語入力の末尾からそのまま日本語入力を再開できます。

## 英字混じりの文

英字区間に続いて日本語の助詞などを打鍵すると、英単語の終了を検知して自動的に日本語入力へと復帰します。

- **日本語への自動復帰**: 英単語の入力後、続く入力が英単語の前方一致にならなくなった時点で英字区間が自動で閉じられ、残りの入力がローマ字として日本語に変換されます（例: `kyouhagithubdesagyousuru` → 「きょうはgithubでさぎょうする」、`pythonwotukau` → 「pythonをつかう」）。
- 1 つの入力文の中に複数の英字区間が含まれていても問題ありません（例: 「きょうはgithubでpythonをつかう」）。
- 英字区間と日本語区間が混在している状態で変換キーを押すと、英字部分はそのまま維持され、日本語部分のみが適切に漢字変換されます（例: 「今日はgithubで作業する」）。

## 英単語の大文字小文字の補正

固有名詞や技術用語など、特定の大文字・小文字表記を持つ英単語（`github` に対する `GitHub` など）は、適切な大文字表記が自動補正候補として提示されます。

- **自動での強制変換は行いません**: 勝手に書き換えることはせず、候補として提示されます。正しい表記は、同梱の技術用語辞書 (`english-names.txt`) およびユーザー辞書から取得されます。
- **変換キーでの選択**: 変換キーを押すと、大文字補正された表記（例:「今日はGitHubで作業する」）が最上位に、入力どおりの小文字表記がその下に並びます。小文字表記を選んで確定した場合は、学習機能により次回以降その表記が優先されます。
- **候補バーでの採用**: 英字の入力中、候補バーの先頭に大文字補正された候補（例: `きょうはGitHub`）が表示されます。

## 日本語区間がある run の候補バー

日本語部分と英字部分の両方が含まれる入力中の候補バーの動作は以下のとおりです。

- 日本語部分が候補バーの表示を始める文字数（`min_suggest_chars`）以上ある場合に候補バーが表示されます。
- 候補バーには日本語部分を変換した候補に英字部分を付加した形で表示されます（例:「今日はgithub」）。
- 候補を採用すると日本語部分のみが漢字に置き換わり、英字部分は引き続き入力状態として維持されます。

## 英字モード中のキー

モードレス入力が ON のときの英字モード中（自動判定・`Shift + 英字` のどちらで開始した場合も共通）のキー挙動です。

- **Space**: 設定 `space` が「全角」に設定されていても、常に**半角スペース**を入力して確定します。
- **変換キー**: 候補選択に入ります（大文字小文字の変換候補 `apple` / `Apple` / `APPLE` や、固有名詞補正 `GitHub` が選べます）。
- **記号キー**: 常に半角文字で入力されます。
- **Enter**: 入力をそのまま確定し、アプリへ Enter を送ります。

## 英字にならない場合

以下のようなケースでは、日本語の入力を優先するため自動的には英字になりません。

- ローマ字として自然な日本語になる英単語（`sake`、`name`、`date`、日本語の後に続く `pen` など）。これらは変換キーでの半角英字候補や、`F10` キー、または `Shift + 頭文字` の手動英字入力で入力してください。
- 文頭を大文字で開始した場合（`Shift + 英字` による入力は、明示的な英字入力とみなされます）。
