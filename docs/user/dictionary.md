# 辞書とローマ字

## 単語登録

変換で出ない単語や専門用語は、単語登録ツール (`quicklime-regword.exe`) を使ってユーザー辞書に登録できます。

### 起動方法と使い方
文字を入力していない待機状態で `Ctrl + F7` (`key.register_word`) を押すか、タスクバーの通知領域にある入力モードアイコンを右クリックして「単語登録...」を選択します。「単語」「よみ」「品詞」を入力して「登録」ボタンをクリックします（`Enter` でも登録できます。`Esc` で閉じます）。

- **開けないアプリ**: スタートメニューの検索欄や、Microsoft Store から入れたアプリ (UWP アプリ) の一部では、`Ctrl + F7` や入力モードアイコンのメニューから単語登録ツールを開けません（何も起きません）。メモ帳などほかのアプリで開いてください。
- **結果の表示**: 登録できると、ウィンドウの上部に結果を表示してから閉じます。エンジンが起動していないときはユーザー辞書ファイルへ直接追記し、その旨を表示したまま開いておきます（反映は次回のエンジン起動時）。入力が空のときや登録できなかったときも、上部に表示して開いたままにします。
- **選択テキストの自動入力**: 文書内で登録したい文字列を選択した状態でキー操作（`Ctrl + F7`）で単語登録ツールを開くと、選択したテキスト（1 行目のみ）が自動的に「単語」欄に入力されます。入力モードアイコンの右クリックメニューから開いたときは入力されません。
- **読みのカタカナ**: 「よみ」欄にカタカナを入力した場合、自動的にひらがなへ変換されて登録されます。
- **品詞の分類**:
  - **名詞系（名詞・固有名詞・人名・姓・名・地名・組織）**: 長い文の途中でも自然に変換されます。同じ読みの一般的な名詞よりも優先して上位に表示されやすくなります。
  - **短縮よみ**: メールアドレスや挨拶文、定型フレーズなど、入力した読みから表記をそのまま展開したい場合に選びます。変換候補では、既定の変換（`segment_ui: 0`）だと入力全体の変換候補（区切り方を変えた候補や数字の書き方を変えた候補を含む）の後ろに、文節単位の変換（`segment_ui: 1`）だとその文節の最良候補と、その読みで以前に確定した表記の後ろに表示されます。予測候補では最優先で先頭に表示されます。
- **即時反映**: 登録した単語はエンジンの再起動なしですぐに入力・変換に利用できます（通常の変換、予測候補、`F5` キーによるユーザー語変換のすべてに対応）。

### ユーザー辞書ファイル (`userdict.tsv`)
登録された単語は `%APPDATA%\QuicklIME\userdict.tsv` (UTF-8) に保存されます。
- 書式は 1 行 1 単語の `読み<TAB>表記<TAB>品詞[<TAB>コメント]` です（Mozc のユーザー辞書エクスポート形式と互換）。
- 行頭が `#` の行はコメント行として扱われます。品詞列が省略されている行は「短縮よみ」として解釈されます。
- テキストエディタで直接編集した場合は、エンジンの再起動時、または単語登録ツールで次にインポートして 1 語以上を取り込んだ際に反映されます。取り込める語が 1 語も無かったインポートでは反映されません。その場合は、タスクマネージャーで `quicklime-engine.exe` を終了するか、サインアウトして入り直してください（エンジンは次に文字を入力したときに自動で起動し直します）。

## 辞書インポート

他の日本語 IME からエクスポートしたユーザー辞書や、公開されている各種専門辞書（ニコニコ大百科 IME 辞書、pixiv 辞書など）を一括して取り込むことができます。

### インポート手順
単語登録ツールの「インポート...」ボタンをクリックし、対象の辞書ファイルを選択します。インポート結果（取り込み件数、重複件数、未対応品詞、スキップ行数など）がウィンドウの上部に表示され、起動中のエンジンに即座に反映されます。

### 対応フォーマット
以下の主要な IME 辞書形式を自動判別して取り込みます。

| 形式 | 判別基準 | 備考 |
|---|---|---|
| MS-IME | 先頭行が `!Microsoft IME Dictionary Tool` | `!` で始まる行はヘッダーとして扱われます |
| ATOK | 先頭行が `!!ATOK_TANGO_TEXT_HEADER_1` | `!` で始まる行はヘッダーとして扱われます |
| Mozc / Google 日本語入力 | 上記以外 | `#` で始まる行はコメントとして扱われます |

- **文字コード**: UTF-16 (BOM 付き)、UTF-8 (BOM の有無を問わず対応)、Shift_JIS を自動判別します。
- **対応品詞**: 名詞系および短縮よみを取り込みます（顔文字・記号は下の表のとおり短縮よみとして取り込みます。動詞、形容詞、副詞など、下の表にない品詞の語はスキップされます）。どの形式でも、品詞の末尾の `$` や `*`（ATOK が付けるもの）は無視して品詞を判断します。

| 元の辞書の品詞 | QuicklIME での取り込み先 |
|---|---|
| 人名, 固有人他, 固有人名(姓名) | 人名 |
| 姓, 固有人姓 | 姓 |
| 名, 固有人名 | 名 |
| 地名, 固有地名, 地名その他 | 地名 |
| 組織, 固有組織, 社名 | 組織 |
| 固有名詞, 固有一般, 固有商品, 物品, その他「固有」から始まる品詞 | 固有名詞 |
| 短縮よみ, 短縮読み, 顔文字, 記号 | 短縮よみ |
| 普通名詞, さ変名詞, 名詞サ変, 形動名詞, その他「名詞」を含む品詞 | 名詞 |

### 重複と保存先
- ファイル内の重複や、すでにユーザー辞書 (`userdict.tsv`)・他のインポート済み辞書に存在する単語は自動的にスキップされます。
- インポートした辞書は `%APPDATA%\QuicklIME\imported\<元ファイル名から拡張子を除いた名前>.tsv`（`nicoime.txt` なら `nicoime.tsv`）として個別に保存されます。同名のファイルを再インポートした場合は上書き更新されます。
- インポートした辞書を解除したい場合は、該当の `.tsv` ファイルを削除してください（エンジンの再起動時、または次にインポートして 1 語以上を取り込んだ際に反映されます。エンジンの再起動のしかたは上の「ユーザー辞書ファイル」と同じです）。
- インポートした単語は、手動登録した単語よりは控えめな優先度で変換候補や予測候補に表示されます。

## ローマ字テーブルのカスタマイズ

既定のローマ字入力を変更したい場合、`%APPDATA%\QuicklIME\romaji.tsv` (UTF-8) を作成して配置することで、ローマ字の変換テーブルを自由に追加・上書きできます。

- **書式**: 1 行 1 定義の `ローマ字<TAB>かな`
- 行頭が `#` の行はコメント行です。
- かな欄を空にした行を書くと、既定のローマ字定義を削除できます。
- ローマ字の欄の英大文字は小文字として扱います。
- 3 列目（Google 日本語入力形式の「次の入力」）のある行は読み込まれません。
- 設定変更は各アプリを再起動した後に反映されます。

### AZIK プリセットの導入
効率的な入力方式として知られる AZIK 風の拡張定義（撥音拡張「かん」= `kz`、二重母音拡張「こう」= `kp` など）のプリセットファイルを用意しています。

- インストール版では `%ProgramFiles%\QuicklIME\presets\romaji-azik.tsv` に同梱されています。
- リポジトリ内では [data/romaji-azik.tsv](../../data/romaji-azik.tsv) にあります。

AZIK を利用する場合は、このファイルを `%APPDATA%\QuicklIME\romaji.tsv` へコピーしてください。

```powershell
# PowerShell での配置例 ($env:APPDATA を使用)
copy-item "C:\Program Files\QuicklIME\presets\romaji-azik.tsv" "$env:APPDATA\QuicklIME\romaji.tsv"
```
