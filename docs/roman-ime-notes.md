# Roman (ローカル LLM の IME) の調査メモ

記事「[Roman](https://zenn.dev/mobazou/articles/roman-local-llm-ime)」(macOS 向けの IME) の要点と、QuicklIME で
参考にできる点。

## 記事の要点

- 変換キーを押さず、打鍵の停止 200ms で変換し、表示中の文字列を自動で書き換える。無入力 1100ms で自動確定
- 候補は Mozc 辞書のラティスだけから作る。順位は ユーザの学習 > 日本語の規則 > BERT の採点 > qwen の番号の択一。
  qwen に自由に生成させない。zenz は辞書に無い綴りのときだけ呼ぶ
- 左文脈の無い場面 (文頭・改行・句点の直後) では BERT を使わない。1 位の一致は BERT 61%、辞書のコスト 77〜80%
- 打ち間違いの判定にラティスの 1 文字あたりのコストを使う。正しい語 1044〜1933、誤打 2143〜3391 で分かれた
- かなとして成り立つが不自然な読み (こにちわ) の自動訂正は廃止。20 文中 11 回誤発動し、すべて語の打ち終わり前の
  断片 (こんしゅ → こんしゅう) だった。読みを変える訂正は自動で適用せず、候補一覧に並べる
- 学習は候補一覧で選んだときだけ。使うたびに優先度を下げ、辞書が自力で同じ答えを出せるようになったら消す
- 単語登録はよみを尋ねない。打鍵の履歴と出力した文字列の対応を持ち、確定した文字列を分割して打鍵由来の読みと
  照合できたものだけ使う
- 辞書の拡充
  - 長い語を安いコストで足すと、助詞をまたいで経路を乗っ取る (はいせんがん → 「は胃腺癌」)。コスト 8000 で
    解消し、Mozc の読み 300 件・一般文 32 件で 1 位の変化はゼロだった
  - 既にある読みには足さない。194 語で試すと 13 語で一般語の 1 位が崩れた (こうし → 鉤歯 など)
  - SKK-JISYO.L は GPL-2.0 のため使わない。JMdict (CC BY-SA 4.0) は EDRDG の利用許諾の定期更新の条件のため、
    生成日が 90 日より古ければビルドを止める

## QuicklIME で参考にできる点

QuicklIME は文書を自動で書き換えない ([input.md](spec/input.md)「原則」) ので、記事の時間の設計 (保留・
書き換えの禁止時間・自動確定・Enter 直前の書き換えの保護) はそのままでは使えない。

| 点 | QuicklIME の該当箇所 | 扱い |
|---|---|---|
| 打ちかけの読みでの補正の誤発動 | 打ち間違いの無い文を 1 打ずつ打った途中の状態で、補正の候補かずれのある予測が候補バーの先頭に出る。末尾の保護なしで 10%、今は 2% (fuzzy_eval)。残りは末尾から 2〜3 文字目の補正 (すみま → 隙間) | 補正で読みの末尾 1 文字を変えない ([engine.md](spec/engine.md)「ファジィ入力」) |
| 1 文字あたりのコストそのものを補正の判定に足す | Δ は通常と補正の経路の差だけを見る | 見送り。打ち間違いの無い文を途中で切った読みのコストが打ち間違いのある文と重なる (中央値 1851 と 2094、打ち間違いの無い文で 0% になる 2750 以上が途中で切った読みで 8%・打ち間違いのある文で 14%。typo_eval) |
| 並べ替えの結果が採用の直前に届く | 組み直しを止める条件 ([suggest.md](spec/suggest.md)「LLM の並べ替えの結果の反映」) | 未検討 |
| 辞書だけで同じ答えが出る学習を消す | 文節境界の学習を消す手段が無い ([roadmap.md](roadmap.md)) | roadmap |
| 英字の残った読みから学習しない | `kyouhak` の学習 ([roadmap.md](roadmap.md)「見送り・既知の問題」) | 未検討 |
| 単語登録のよみを打鍵の履歴から埋める | TSF 層はよみを渡さない ([dictionary.md](spec/dictionary.md)「単語登録ツール」) | roadmap |
| 語を足すときの乗っ取りの確認 | インポート辞書の語は 5000 ([dictionary.md](spec/dictionary.md)「語のコスト」) | 未検討 |
| LLM の生成の候補の変換の取り残し (メールをそうしん) | 生成の後処理 ([engine.md](spec/engine.md)「後処理」) | 未検討 |
