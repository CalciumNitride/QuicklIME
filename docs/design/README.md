# 設計書の索引

設計書は実装前の合意の置き場所。今の仕様は仕様書 ([docs/spec/README.md](../spec/README.md)) を見る。
設計書から仕様書への変更の流れは [docs/spec/README.md](../spec/README.md)「変更の流れ」にある。

## 書く内容

- 背景と目的
- 決定事項 (採用した案と、採らなかった案とその理由)
- 変更対象ファイル (書き換える仕様書と節を含める)
- 実装手順
- 検証方法
- 未決事項 (該当があれば)

実装中に設計が変わったときだけ、該当箇所を最新の内容に書き換える。実装後は内容を仕様書へ移し、
設計書を docs/archive/ へ移す。

## 進行中の設計書

今は無い。
