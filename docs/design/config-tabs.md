# 設定ツールのタブ化

設定ツール (engine/src/bin/quicklime-config.rs) のメイン画面を、項目のまとまりごとのタブに分ける。

## 背景と目的

メイン画面は1枚のウィンドウに、左カラムの「変換」「入力」「候補ウィンドウ」の3グループと、
右カラムの「キー割当」の一覧を並べた2カラム構成になっている。改行キーの対象アプリの一覧
(docs/design/newline-key.md) など項目が増えると、1枚に収めると見通しが悪くなる。項目のまとまりごとに
タブで分け、項目を足す余地を作る。

## 決定事項

### タブの構成

| タブ | 中身 |
|---|---|
| 変換 | 学習する、入力中にサジェストを表示する、タイプミス補正、サジェスト件数、サジェスト開始文字数、文節単位で変換する、AI で候補を並べ替える、AI の実行環境 |
| 入力 | スペースキー、句読点、数字、モードレス入力 |
| 表示 | 候補バーを表示する、フォント、サイズ |
| キー割当 | キー割当の一覧、[編集...] [既定に戻す] |
| アプリ | 改行キーの対象アプリ (中身は docs/design/newline-key.md) |

- 既存の項目の中身・並び・設定キーは変えない。グループの見出し (「変換」「入力」「候補ウィンドウ」)
  はタブ名が兼ねるので置かない
- 「アプリ」タブは、将来アプリ別の設定を足す場所も兼ねる

### 画面の作り

- メインウィンドウの上部にタブコントロール (`SysTabControl32`) を1つ置き、その下に共通の
  [保存] [キャンセル] を右寄せで置く
- 各タブのコントロールは、これまでどおりメインウィンドウの子として作る。どのタブに属するかを
  覚えておき、タブの切替 (`TCN_SELCHANGE`) で表示・非表示を切り替える
  - タブコントロールの子にしないのは、コントロールの通知 (`WM_COMMAND`・`WM_NOTIFY`) を
    今のウィンドウプロシージャでそのまま受けられ、`collect` (保存時に全コントロールから値を
    読む処理) も変えずに済むため。非表示のコントロールの値も読める
  - 重なり順はタブコントロールを最背面にする (コントロールがタブの下に隠れないように)
- 起動時は「変換」タブを表示する。最後に開いたタブは覚えない
- Ctrl+Tab / Ctrl+Shift+Tab で次・前のタブに切り替える (メッセージループで、`IsDialogMessageW` より
  先に処理する)。Tab キーでのフォーカス移動は表示中のタブのコントロールと共通ボタンだけを巡る
  (非表示のコントロールは `IsDialogMessageW` が飛ばす)
- ウィンドウは固定サイズ。幅は1カラム分 (ラベル + コントロール) とキー割当の一覧の幅の大きい方、
  高さはいちばん項目の多いタブ (変換: 8行) とキー割当の一覧が収まる高さにする
- `InitCommonControlsEx` に `ICC_TAB_CLASSES` を足す

## 変更対象ファイル

| ファイル | 変更内容 |
|---|---|
| engine/src/bin/quicklime-config.rs | メイン画面のレイアウトをタブ構成に組み替える。タブの切替と Ctrl+Tab の処理 |
| README.md | 設定ツールの画面の説明があれば、タブ構成に合わせる |

## 実装手順

1. タブコントロールと共通ボタンを置き、既存の項目を「変換」「入力」「表示」「キー割当」の各タブに
   振り分ける。「アプリ」タブは空のまま作る (中身は改行キーの実装で足す)
2. タブの切替による表示・非表示と、Ctrl+Tab / Ctrl+Shift+Tab
3. ウィンドウの大きさの調整
4. ビルドと `cargo test`

## 検証方法

`QUICKLIME_CONFIG_FILE` で隔離した config.tsv を使って設定ツールを起動する。

### テストケース

| # | 操作 | 期待 |
|---|---|---|
| 1 | 起動する | 「変換」タブが表示され、既存の値が読み込まれている |
| 2 | 各タブをクリックで切り替える | そのタブの項目だけが表示され、ほかのタブの項目が重なって見えない |
| 3 | Ctrl+Tab・Ctrl+Shift+Tab | 次・前のタブに切り替わる (末尾から先頭へ、先頭から末尾へ回る) |
| 4 | 各タブで Tab キーを押し続ける | 表示中のタブの項目と [保存] [キャンセル] だけをフォーカスが巡る |
| 5 | 複数のタブの値を変えて、最後に別のタブで保存する | 全タブの変更が config.tsv に書かれる |
| 6 | 値を変えてキャンセル | config.tsv は変わらない |
| 7 | 「キー割当」タブで編集・既定に戻す | 既存どおり働く |
| 8 | 表示倍率 100%・150% で起動する | 各タブの項目がはみ出さず、切れない |
