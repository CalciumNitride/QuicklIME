# モードレス入力 (自動英字判定)

## 背景と目的

半角/全角キーで IME をオン/オフせずに、日本語と英語を混ぜて打てるようにする。
英語の打鍵列を IME が自動で見分けてアルファベットのまま入れ、日本語の打鍵列は
従来どおりかな漢字変換する。

前提として direct 方式 (docs/design/direct-input.md) の上に載せる。判定と英字モードの
扱いは RomajiComposer 層に入れる。

既存の部品:

- 英字モード: Shift+英字で入り、以降はローマ字変換せずアルファベットのまま続く
  (romaji.h の `asciiMode_`)
- 生ローマ字候補: 「apple」を変換すると apple / Apple / APPLE が候補に出る
- ローマ字不成立文字の素通し: romaji.cpp `Convert()` の末尾で「どの規則にも合わない
  先頭文字はそのままかな列へ残す」。英単語の打鍵で必ずここを通る

## 決定事項

### 設定と IME オン/オフ

- 設定 `modeless` (0/1、既定 0) で有効化する。設定ツールにチェックボックスを追加する
- IME オン/オフ (半角/全角キー、言語バー) はそのまま残す。パスワード欄やターミナルで
  IME を完全に黙らせる手段は必要で、モードレスは「オン/オフを使わなくて済む」機能と位置づける

### 自動英字判定 (RomajiComposer)

判定ルールの追加 (ルール4〜7)、判定が成立したときに英単語の部分だけを英字にする区間分割、
英単語の始まりの決め方、ルール3 を適用する場所の追加 (確定キー・記号キー) は
docs/design/modeless-detection.md にある。本節の「run 全体を英字モードへ遷移させる」
「Backspace で空になるまで英字モード」は、そちらの区間分割で置き換えている。

判定は打鍵ごとに `Convert()` の中で行い、成立した時点でその run を
英字モードへ自動遷移させる。遷移時は打鍵列 `Raw()` + 未変換ローマ字からかな列を
作り直し (各文字がそのまま1文字のかな扱い、raw も同じ1文字)、`asciiMode_ = true`
にする。以降は Shift+英字で入った英字モードと同じ扱い。

判定ルール (いずれかで英字):

1. ローマ字不成立の素通しが起きた (`Convert()` 末尾の分岐に英小文字が来た)。
   「str」「th」「xt」「rl」など英語特有の子音連続はテーブルの接頭辞に無いのでここで拾える。
   例: apple → あっp で p が素通し → 英字
2. 促音「っ」の直後に l/x 由来の小書き母音 (ぁぃぅぇぉ) が来た。
   例: hello → へっぉ → 英字
3. 確定文字列を作るときに、未変換ローマ字として n 以外の子音が1文字残っている。
   例: want → わんt → 英字 (Space や Enter で確定するときに want になる)

ルール3 は文書の表示も英字に直せる場所でだけ適用する。Space と、読める文書で
Enter・矢印などを食べずに通すとき (`EndRunIfPassthroughKey`。run を終える前に
surface を置き換える)。追記のみの文書 (docs/design/append-input.md) で食べずに通すキーでは
適用しない (作り直しの擬似 Backspace がそのキーより後にアプリへ届き、別の文字を消すため)。
フォーカス移動・IME オフでの run 終了でも適用しない (文書は「わんt」のままなので、
学習も「わんt」で揃える)。
Ctrl/Alt 併用のショートカット (Undo など) でも適用しない。確定ではないうえ、
直後の Undo がルール3 の書き換えの方を取り消してしまうため。

判定しないもの (日本語優先。従来どおり Shift 頭文字か生ローマ字候補で対応):

- ローマ字として成立する英単語 (sake, name, date, one, made など)
- 大文字始まり (既存の Shift+英字で明示的に英字モードに入る)

一度英字モードに入った run は日本語には戻らない。Backspace で空になれば `Clear()` で
解除され、次の run は日本語から始まる。

採らなかった案: 英単語辞書の同梱や統計的な言語判定。判定精度は上がるが辞書配布と
メモリのコストがあり、まずルールベースで実用性を確かめる。

### 英字モード中のキーの意味

設定 `modeless` が有効なときだけ、自動判定・Shift 由来を問わず英字モード中は次のようにする。
`modeless` が無効なら Shift+英字で入った英字モードも従来どおり (Space は設定どおりの幅の
スペース) で、既定の挙動は変わらない。

| キー | 挙動 |
|---|---|
| Space | 半角スペースを入れて run 終了 (設定 space に関わらず半角)。候補選択中は次候補ではなく、確定して半角スペースを入れる |
| 記号 (. , ' ; / など) | 半角のまま (既存どおり) |
| Enter | 食べない (改行) + run 終了 |
| 変換キー | 候補選択へ (生ローマ字候補で大文字化など) |

Apple / APPLE の切替は候補選択中の生ローマ字候補と、既存の F9/F10 連打で行う。

run が無いときの Space は、直前の run の surface が英字のみなら半角、それ以外は
設定 space に従う (文頭以外の英文中のスペースは run 終了の Space で入るので、
実質は保険)。

## 変更対象ファイル

| ファイル | 変更 |
|---|---|
| tsf/src/romaji.h / romaji.cpp | 自動判定 (ルール1・2 を `Convert()` 内、ルール3 を run 終了用の `FinishForCommit()` など明示メソッド)、`Raw()` からの英字モード再構成、`modeless` フラグの受け渡し (テーブルと同様にプロセス内設定として渡す) |
| tsf/src/config.h / config.cpp | `modeless` の読み込み |
| tsf/src/text_service.cpp / text_service_direct.cpp | 英字モード中の Space (半角スペース + run 終了/確定)、run なし Space の半角追随 |
| engine/src/bin/quicklime-config.rs | `modeless` のチェックボックスと書き出し |
| README.md / docs/roadmap.md | 機能説明の追記 |

エンジンとプロトコルは変更しない。

## 実装手順

1. config: `modeless` の読み込みと設定ツールの項目
2. romaji: 英字モード再構成 (`Raw()` + pending → かな列) の実装と単体テスト相当の確認
   (romaji.cpp にテストが無ければ、既存の確認方法に合わせる)
3. romaji: ルール1・2 を `Convert()` に、ルール3 を run 終了時の呼び出しに追加。
   `modeless` が 0 なら一切発動しない
4. text_service: 英字モード中の Space の挙動、run なし Space の半角追随
5. 手動テスト

## 検証方法

反映と隔離は direct-input.md と同じ。設定ファイルに `modeless\t1` を入れる。

| # | 操作 | 期待 |
|---|---|---|
| 1 | `apple` | `あっp` の次の `l` で英字と判定され `appl` に置き換わり、以後 `apple` |
| 2 | `hello world` | `hello` の `へっ` + `ぉ` で英字へ。Space で半角スペースが入り run 終了。`world` は `を` → `wor` の時点で英字へ |
| 3 | `this is a pen.` | `this` と `is` は Space でルール3 が効いて英字になり、スペースは半角。`pen` はローマ字として成立するため `ぺん` のままで、`.` も全角の `。` になる (ローマ字として読める語を判定しない設計上の限界) |
| 4 | `want ` (Space) | `わんt` から Space で `want` + 半角スペース (ルール3) |
| 5 | `sake ` | 日本語優先で `さけ　` (全角スペース、space=full)。変換キーで候補選択に入ると生ローマ字候補 sake が出る |
| 6 | `kyouha` | 日本語のまま (誤判定しない) |
| 7 | `Apple` (Shift) | 従来どおり英字モード、Space で半角スペース付きで終了 |
| 8 | `apple` を打った後 Backspace で全部消し `kyou` | 日本語に戻る |
| 9 | `modeless\t0` | 1〜4 が従来どおり (素通し文字が残るだけ) |
| 10 | modeless 1 で `apple` 変換キー → Space | `apple ` が確定される (次候補にならない) |
