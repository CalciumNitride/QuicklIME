# 設定ツールのアプリ別設定

設定ツール (engine/src/bin/quicklime-config.rs) の「アプリ」タブを、アプリを1つの一覧に並べ、
アプリごとに各設定を変える画面にする。今の設定は改行キー (docs/design/newline-key.md)、
起動時の IME の状態 (docs/design/ime-start-state.md)、学習の停止 (docs/design/no-learning-apps.md)、
追記のみ扱い (docs/design/append-only-apps.md) の4つ。

## 背景と目的

「アプリ」タブには、改行キーの対象アプリの一覧だけがある。アプリ別の設定を足すたびに設定ごとの一覧を
並べると、同じアプリが何か所にも出て冗長になり、あるアプリにどの設定をしているかも見通しにくい。
アプリを軸にした1つの一覧にまとめ、アプリ別の設定を足すときは列と編集欄に1項目ずつ足す形にする。

## 決定事項

### 画面

```
アプリごとの設定
┌──────────────────────────────────────────┐  [実行中のアプリから追加...]
│ exe 名              │ 改行キー │ 起動時の IME │  [ファイルから追加...]
│ Discord.exe         │ ✓       │ 自動         │  [削除]
│ Notepad.exe         │         │ オン         │  [既定に戻す]
│ WindowsTerminal.exe │         │ オフ         │
└──────────────────────────────────────────┘
選択中のアプリの設定
  [ ] 改行キー (Ctrl+J など) で Shift+Enter を送る
  起動時の IME: [オン ▼]
```

- 見出し「アプリごとの設定」の下に一覧 (ListView、単一選択、行全体の選択) を置き、右にボタンを縦に並べる
  (今の配置のまま)
- 一覧の列は「exe 名」「改行キー」(有効なら `✓`、無効なら空)「起動時の IME」(`自動` / `オン` / `オフ`)
- 一覧の下に、選んでいるアプリの編集欄を置く
  - チェックボックス「改行キー (Ctrl+J など) で Shift+Enter を送る」
  - コンボボックス (ドロップダウンリスト)「起動時の IME」: `自動` / `オン` / `オフ`
  - 変えるとすぐ一覧の列に反映する。何も選んでいないときは編集欄を無効にする
  - 「自動」の意味 (アプリやシステムに任せる) は、編集欄の近くに説明を1行添える
- [実行中のアプリから追加...] [ファイルから追加...]: 今のダイアログをそのまま使う
  (docs/design/newline-key.md「実行中のアプリから選ぶダイアログ」「ファイルから追加」)。
  追加したアプリは「改行キーなし・自動」から始め、その行を選ぶ。すでにある exe は重ねて追加せず、その行を選ぶ
- [削除]: 選んでいるアプリを一覧から外す (そのアプリの設定がすべて消える)。次の行を選ぶ
- [既定に戻す]: 改行キーの既定の5アプリ (改行キーあり・自動) だけの一覧に戻す
- 変更は設定ツール内の状態に持ち、共通の [保存] で config.tsv に書く。[キャンセル] では書かない

### 設定ファイルとの対応

- config.tsv のキーは機能ごとに分けたままにする: `newline_apps` (今の形式) と `ime_start_apps`
  (docs/design/ime-start-state.md)。TSF 層の読み方と既存の設定ファイルとの互換性は変えない
- 設定ツールの中では、アプリごとの設定 (exe 名・改行キーの有無・起動時の IME) の一覧として持つ
- 読み込み: `newline_apps` の順にアプリを並べ (改行キーあり)、続けて `ime_start_apps` にだけあるアプリを
  その順に足す。exe 名の照合は大文字小文字を区別しない。`newline_apps` の行が無ければ既定のリストを使う
  (今と同じ)
- 保存: 改行キーありのアプリを一覧の順に `newline_apps` へ、起動時の IME が自動でないアプリを一覧の順に
  `ime_start_apps` へ書く。どちらも空なら空の値で書く (`newline_apps` を空で書くと対象なしになる。今と同じ)
- どの設定も既定 (改行キーなし・自動) のアプリは、どちらのキーにも書かれないので、開き直すと一覧から
  消える。設定の意味は変わらないので、そのままにする

## 変更対象ファイル

| ファイル | 変更内容 |
|---|---|
| engine/src/bin/quicklime-config.rs | アプリごとの設定の一覧 (今の `NEWLINE_APPS` を置き換える)、`ime_start_apps` の読み書き、「アプリ」タブの列と編集欄、ボタンの動作、テスト |
| README.md | 「アプリ」タブの説明を新しい画面に合わせ、起動時の IME の状態を足す |
| docs/design/newline-key.md | 「アプリ」タブの節を、本書を指すように書き換える |
| docs/design/README.md | 本書を索引に足す |

## 実装手順

1. アプリごとの設定の一覧の型と、`newline_apps`・`ime_start_apps` からの読み込み・保存 (単体テストを含む)
2. 一覧の列、編集欄、ボタンの動作を新しい型に合わせる
3. ウィンドウの大きさの調整 (「アプリ」タブの高さが増えるので、ほかのタブとの釣り合いを確かめる)
4. ビルドと `cargo test`
5. ドキュメント: README.md

## 検証方法

`QUICKLIME_CONFIG_FILE` で隔離した config.tsv を使って設定ツールを起動する。

### テストケース

| # | config.tsv | 操作 | 期待 |
|---|---|---|---|
| 1 | `newline_apps`・`ime_start_apps` の行なし | 「アプリ」タブを開く | 既定の5アプリが「✓・自動」で並ぶ |
| 2 | `newline_apps Discord.exe`、`ime_start_apps Notepad.exe:on,discord.exe:off` | 開く | Discord.exe (✓・オフ)、Notepad.exe (空・オン) の2行。Discord は重ならない |
| 3 | 2 と同じ | Notepad.exe を選び、起動時の IME を「オフ」、改行キーをオンにして保存 | `newline_apps Discord.exe,Notepad.exe`、`ime_start_apps Discord.exe:off,Notepad.exe:off` が書かれる |
| 4 | 任意 | 何も選んでいない状態にする (一覧を空にする) | 編集欄が無効になる |
| 5 | 任意 | [実行中のアプリから追加...] でメモ帳を足す | Notepad.exe が「空・自動」で追加されて選ばれる。登録済みの exe はダイアログに出ない |
| 6 | 任意 | [ファイルから追加...] で一覧にすでにある exe を選ぶ | 重ならず、その行が選ばれる |
| 7 | 任意 | 行を選んで [削除] → 保存 | そのアプリが `newline_apps`・`ime_start_apps` のどちらからも消える |
| 8 | 任意 | [既定に戻す] → 保存 | `newline_apps` が既定の5つ、`ime_start_apps` が空で書かれる |
| 9 | 任意 | アプリを足して「空・自動」のまま保存し、開き直す | そのアプリは一覧に出ない |
| 10 | 任意 | 変更してから [キャンセル] | config.tsv は変わらない |
| 11 | 任意 | Tab キーでフォーカスを巡らせる | 一覧・編集欄・ボタンを巡り、編集欄の変更が一覧に反映される |
| 12 | 任意 | 表示倍率 100%・150% で開く | 列・編集欄・ボタンがはみ出さず、切れない |
