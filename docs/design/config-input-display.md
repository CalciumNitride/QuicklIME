# 設定ツールの入力中の読みの表示先と入力モード表示の文言

## 背景と目的

設定ツールでは、入力中の読みをどこに出すかが 2 か所に分かれていた。

- 「入力」タブの「入力中の読み:」(`input_buffer`): 文書に下線付きで出す / 入力パネルだけに出す
- 「表示」タブのチェックボックス「入力中の読みも候補と同じ場所に表示する」(`panel_input`)

チェックボックスの「候補と同じ場所」は入力パネルを指すと読み取れない。また `input_buffer panel` のときは
入力行が常に出るため、チェックボックスを変えても何も起きない。

「表示」タブの「切り替えたときに入力モードをキャレットの近くに表示する」(`mode_popup`) も、
何が出るのかが分かりにくく、文言が長い。

## 決定事項

### 入力中の読みの表示先を 1 つのコンボにまとめる

「入力」タブの「入力中の読み:」の選択肢を 3 つにし、「表示」タブの `panel_input` のチェックボックスを
なくす。設定キーと TSF 層の挙動は変えない (変わるのは設定ツールの画面と読み書きだけ)。

| 選択肢 (並び順) | 書く値 |
|---|---|
| 文書に下線付きで出す (既定) | `input_buffer composition`、`panel_input 0` |
| 文書と入力パネルの両方に出す | `input_buffer composition`、`panel_input 1` |
| 入力パネルだけに出す | `input_buffer panel`。`panel_input` は読み込んだ値のまま書く |

- 読み込み時は、`input_buffer` が `panel` なら「入力パネルだけに出す」、そうでなければ `panel_input` の
  値で 1 番目か 2 番目を選ぶ
- 「入力パネルだけに出す」で `panel_input` を読み込んだ値のまま残すのは、手で書いた config.tsv の値を
  設定ツールで保存しただけで変えないため (`panel_input` はこのとき効かないので、どちらでも挙動は同じ)
- 「文書と入力パネルの両方に出す」は ctrl_w のコンボに収まらないため、このコンボだけ右端をタブの幅いっぱいまで広げる
- テーマの `input_row always` は今までどおり設定によらず入力行を出す。1 番目を選んでいても、
  そのテーマでは入力パネルに入力行が出る

採らなかった案: チェックボックスを「表示」タブに残して文言を直し、`input_buffer panel` のときは
グレーアウトする。読みの表示先を 2 か所で選ぶ構造が残り、タブをまたいだ連動も要るため採らない。

### 入力モード表示のチェックボックスの文言

`mode_popup` のチェックボックスの文言を「オン/オフの切り替え時に「あ」「A」を表示する」にする。
フォーカスが別の入力欄に移ったときにも出ることはラベルに入れず、利用者向けドキュメントで説明する。
文言が短くなり column_w に収まるなら、他のチェックボックスと同じ `check` で置く。

## 変更対象ファイル

- engine/src/bin/quicklime-config.rs: `INPUT_BUFFERS` の選択肢、コンボの初期選択と保存時の読み取り、
  `panel_input` のチェックボックスの削除 (ID 定数が使われなくなれば消す)、`mode_popup` の文言、テスト
- docs/user/input.md・docs/user/settings.md・docs/user/candidate-bar.md・docs/user/theme.md:
  設定ツールでの表記を新しい画面に合わせる (settings.md の表では `panel_input` を
  「入力中の読み (入力)」の 2 番目の選択肢として説明する)
- docs/design/README.md: この設計書を 1 行足す
- 設定ツールの旧文言を引いている設計書 (docs/design/suggest-panel.md・docs/design/mode-popup.md):
  旧文言を新しい表記に直す

## 実装手順

1. 選択肢を (表示名, `panel_buffer`, `panel_input`) の対応で持てる形にし、読み込み・保存を直す
   (「入力パネルだけに出す」の保存では `panel_input` を変えない)
2. 「表示」タブから `panel_input` のチェックボックスを消し、後続の行を詰める
3. `mode_popup` の文言を変える
4. 選択肢と設定値の対応 (3 通りの読み込みと保存) の単体テストを足す
5. ドキュメントを直す

## 検証方法

- `cargo test --bin quicklime-config` と `cargo build --bin quicklime-config`
- 設定ツールの画面で次を確かめる

| # | 操作 | 期待 |
|---|---|---|
| 1 | `input_buffer composition`・`panel_input 0` の config.tsv で開く | 「文書に下線付きで出す」が選ばれている |
| 2 | `input_buffer composition`・`panel_input 1` で開く | 「文書と入力パネルの両方に出す」が選ばれている |
| 3 | `input_buffer panel`・`panel_input 1` で開き、そのまま保存 | 「入力パネルだけに出す」が選ばれ、保存後も `panel_input 1` のまま |
| 4 | 2 番目を選んで保存 | `input_buffer composition`・`panel_input 1` が書かれ、メモ帳で入力パネルの上部に読みが出る |
| 5 | 「表示」タブを開く | 「入力中の読みも〜」のチェックボックスが無く、行の間が空いていない。「オン/オフの切り替え時に「あ」「A」を表示する」が切れずに出る |
| 6 | 「入力中の読み」のコンボを開く | 3 つの選択肢が切れずに出る |
